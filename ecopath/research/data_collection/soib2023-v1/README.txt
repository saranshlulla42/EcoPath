This repository contains the report and its associated results for the State of India's Birds, 2023. For more information, visit https://stateofindiasbirds.in/.

The repository is organized as follows:
  - 00_SoIB 2023.pdf is the main report
  - 02_SoIB_2023_main.xlsx contains a comprehensive set of all results, including those at all spatial extents considered for the report. See the first sheet within it for an overview of how it is organized
  - All remaining files, which are CSVs, are results for each individual spatial extent under consideration. This includes the national, state-wise, across Protected Areas (PAs) and a few habitat type extents.
