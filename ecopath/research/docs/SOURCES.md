# Official documentation and data-access checks

Consulted 20 October 2026. These are implementation references, not ecological observations or a systematic literature review.

- [Hugging Face chat templates](https://huggingface.co/docs/transformers/main/en/chat_templating): native role formatting, add_generation_prompt, training formatting and avoiding duplicate special tokens. The implementation sets return types explicitly because installed Transformers 5 defaults differ from older examples.
- [Hugging Face PEFT quantisation guide](https://huggingface.co/docs/peft/developer_guides/quantization): 4-bit NF4, double quantisation and k-bit preparation/LoRA. This documents API behavior; it does not establish the original run's hardware or effective parameters.
- [LM Format Enforcer](https://github.com/noamgat/lm-format-enforcer) and its [TokenEnforcer source](https://github.com/noamgat/lm-format-enforcer/blob/main/lmformatenforcer/tokenenforcer.py): schema character/token filtering. The installed Transformers bridge had an incompatible tokenizer import; the new small bridge uses the public tokenizer-data/token-enforcer interface. CPU character and actual Qwen token checks pass. Model-generation success remains pending.
- [Ollama structured outputs](https://docs.ollama.com/capabilities/structured-outputs): send a JSON Schema object in `format`, include it in instructions and validate returned data. The fixed-evidence preview uses this API shape; routine tests mock transport. No live Ollama generation was executed.
- [GBIF Data User Agreement](https://www.gbif.org/terms/data-user): official indexed text was inspected for publisher-licence precedence and recommended dataset/record attribution. Direct page retrieval was unavailable through the browsing tool, so this is not a complete current legal-terms review. Before a new dataset collection/release, verify the actual licence on every underlying dataset/record and keep a dated access ledger and download DOI where applicable.
- [IUCN API](https://api.iucnredlist.org/) and [help](https://api.iucnredlist.org/help): indexed official notices state API use is subject to Red List terms; current documentation identifies v4. Direct page retrieval was unavailable. Existing v3 assumptions require review. No new IUCN integration, token use, scrape or redistribution was implemented. Obtain the appropriate authorised access and review full current terms before collecting or releasing records.

No new ecological data-source integration was added. The importer accepts locally curated, licensed, reviewed records. Original platform source adapters remain separate from the experiment. An API token, a model-generated assertion or a public URL alone is not proof of redistribution permission or scientific reliability. Credentials must remain in environment/secret storage, never in prompts, datasets, CLI arguments, logs or manuscripts.

Novelty claims remain pending a proper literature review. Neither this official-documentation check nor the repository audit establishes that no related work exists.
